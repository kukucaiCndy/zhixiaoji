## 一、项目概述

### 1.1 项目定位

纯粹的前端项目（Web SPA），为「知晓记」微信小程序提供运营管理后台。

### 1.2 技术栈

| 技术 | 版本 |
|------|------|
| Vue | 3.5+ (Composition API) |
| TypeScript | 5.7 |
| Vite | 6.x |
| Element Plus | 2.9.x |
| Pinia | 3.x |
| Vue Router | 4.x |
| ECharts | 5.x |
| axios | 1.x |

### 1.3 核心功能模块

| 模块 | 功能描述 |
|------|----------|
| **数据看板** | 核心指标监控、用户趋势分析、内容消费数据、学习转化漏斗 |
| **内容管理** | 知识体系建设、知识卡片 CRUD、题目管理、AI 内容生成、上下架控制 |
| **用户管理** | 用户列表与详情、笔记管理与审核、学习记录、积分记录 |
| **运营管理** | 广告位管理、页面装饰、积分规则、文具管理、等级体系、成就系统、排行榜、限定道具、消息推送 |
| **系统配置** | 账号设置、复习规则配置、日志审计 |

## 三、强制开发要求

### 3.1 工作流程

1. 每次会话必须在上下文中加载本文件（project.md），确保对项目全局有清晰认知
2. 若意图模糊，必须先反问用户确认后再执行
3. 可使用多个 Agent 协同完成任务，提升效率
4. 每次修改完成后必须提交到本地仓库
5. 用户未主动要求时，不得擅自推送到远程仓库
6. 维护 [README.md](README.md) 说明项目内容

### 3.2 接口调用原则

1. **以文档为先**：严格按照后端 SDK/API 文档调用接口
2. **接口问题归因**：SDK 实际行为与文档定义不符时，认定问题在后端，不得强行改变前端业务逻辑来适配
3. **不自行修正**：遇到后端接口问题应当明确记录并反馈

## 四、私有依赖说明

- 私有 npm 仓库：`http://192.168.16.129:4873`，scope `@zhixiaoji`
- Web 端 SDK：`@zhixiaoji/api-sdk-web@0.1.1`（管理后台 API 客户端）
- 小程序 SDK：`@zhixiaoji/api-sdk-wechat@0.7.1`（微信小程序 API 客户端）
- SDK 初始化：[src/api/sdk-client.ts](src/api/sdk-client.ts)，Token key 为 `accessToken`

**安装方式**：

```bash
# npm 直接安装
npm config set @zhixiaoji:registry http://192.168.16.129:4873
npm install @zhixiaoji/api-sdk-web@0.1.1

# 离线 tarball
curl --noproxy '*' -L -o sdk.tgz "http://192.168.16.129:4873/@zhixiaoji/api-sdk-web/-/api-sdk-web-0.1.1.tgz"
npm install ./sdk.tgz
```
