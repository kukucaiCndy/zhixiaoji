## 一、文档概述

### 1.1 文档目的

本文档为「知晓记」小程序管理后台的交互设计规格说明，定义所有页面的页面结构、控件组成、交互逻辑和流程规则，供前端开发和测试团队参考使用。

### 1.2 适用范围

- 所有 Web 管理后台页面的交互逻辑定义
- 不涉及视觉设计元素（配色、字体、阴影等）
- 不涉及技术实现细节（接口定义、数据结构等）
- 此文档仅描述交互行为，UI设计师另行提供视觉稿

## 三、全局交互规范

### 3.1 全局框架布局

页面采用固定布局，分为三个区域：

| 区域 | 位置 | 行为 |
|------|------|------|
| **顶部导航栏** | 页面顶部，固定高度 56px，吸顶 | 始终可见，不随页面滚动 |
| **侧边栏** | 页面左侧，固定宽度 220px，高度撑满除顶栏外的剩余空间 | 始终可见，菜单支持折叠/展开，当前选中菜单高亮 |
| **主内容区** | 右侧剩余区域 | 可滚动，承载各模块页面内容 |

**侧边栏菜单交互：**
- 一级菜单（数据看板、内容管理、用户管理、运营管理、系统配置）默认展开第一项
- 点击一级菜单展开/收起子菜单，已展开的再次点击收起
- 点击二级菜单（知识体系、题目管理等），跳转至对应页面，当前选中项高亮
- 允许多个一级菜单同时展开
- 页面刷新后，展开状态和当前选中项需保持（通过 URL 路由匹配恢复）

### 3.2 通用列表页交互

适用于所有列表型页面（用户列表、卡片列表、题目列表等）。

**组件组成：**
- 搜索栏（输入框 + 搜索按钮）
- 筛选栏（下拉选择器，支持多条件）
- 操作按钮区（新增、批量删除、批量上架/下架、导入、导出）
- 数据表格（表头 + 数据行）
- 分页器

**搜索交互：**
- 输入框占位提示："请输入关键词搜索"
- 输入内容后，按 Enter 触发搜索，或点击搜索按钮
- 输入框右侧显示清除按钮（×），点击清空输入并恢复默认列表
- 搜索过程中，表格区域显示加载状态

**筛选交互：**
- 下拉选择器点击展开选项列表，选中后收起
- 支持多条件组合筛选（如状态 + 时间范围 + 难度）
- 条件变化后自动触发查询，无需额外点击"查询"按钮
- 条件上方显示已激活的筛选标签，点击标签的关闭按钮（×）可单独移除该条件

**表格交互：**
- 表头行固定，数据行可滚动
- 数据行支持 hover 高亮
- 每行左侧有复选框（用于批量操作）
- 表头复选框实现全选/取消全选（仅选中当前页数据）
- 点击某一行任意位置（除操作列外），进入该行对应的详情页（如有）
- 操作列包含：编辑、删除、上架/下架等按钮
- 表格支持按列排序（点击列标题旁的排序箭头），在表头以箭头方向标识当前排序列及升降序

**分页器交互：**
- 位置：表格下方，右对齐
- 显示：共 N 条记录，当前第 X/Y 页
- 控件：上一页、页码按钮、下一页、每页条数切换（20/50/100）
- 页码超过 7 页时，中间页码用省略号（...）表示
- 切换每页条数后，自动跳回第 1 页

**空状态：**
- 无数据时，表格区域显示空状态提示："暂无数据" + 引导操作按钮（如"新增卡片"）
- 搜索无结果时，显示："未找到匹配结果，请调整搜索条件"

**加载状态：**
- 首次加载：表格区域显示骨架屏
- 翻页/搜索/筛选：表格区域显示居中加载动画

**错误状态：**
- 加载失败时显示："加载失败，请点击重试" + 重试按钮

### 3.3 通用表单交互

适用于所有新增/编辑表单页面或弹窗。

**表单布局：**
- 标签在左、输入控件在右，标签宽度统一
- 必填项标签后标记红色星号（*）

**输入控件类型及交互：**

| 控件类型 | 交互说明 |
|----------|----------|
| **文本框 (Input)** | 聚焦时边框高亮，失焦时触发校验，字数限制实时显示计数器 |
| **文本域 (Textarea)** | 聚焦时边框高亮，支持拖拽右下角调整高度，字数限制显示计数器 |
| **下拉选择器 (Select)** | 点击展开选项列表，支持搜索过滤选项，选中后收起，清除按钮置空选择 |
| **开关 (Switch)** | 点击切换开/关状态，即时生效，无需额外保存（仅用于即时配置项） |
| **单选按钮 (Radio)** | 点击切换选中，同一组内互斥 |
| **复选框 (Checkbox)** | 点击切换勾选/取消，独立于其他选项 |
| **数字输入 (Number Input)** | 仅允许输入数字，可设置最小/最大值范围，超出时失焦自动修正为边界值，附带增减步进按钮 |
| **图片上传 (Upload)** | 点击上传区域或拖拽图片至该区域触发上传，上传前本地预览，上传中显示进度条，上传完成后显示缩略图，支持删除已上传图片重新上传 |
| **富文本编辑器** | 详见 3.7 富文本编辑器交互 |

**表单校验：**
- 即时校验：失焦时校验字段，错误提示显示在输入框下方
- 提交校验：点击提交/保存按钮时，校验所有必填项，未通过时滚动至第一个错误字段并聚焦
- 校验规则：必填、格式（邮箱、手机号等）、数值范围、字数限制、唯一性（异步校验）
- 校验未通过时，提交按钮保持可点击状态，再次点击重新触发校验

**表单提交：**
- 提交按钮点击后显示加载状态，禁止重复点击
- 提交成功后：弹窗模式关闭弹窗并刷新列表；独立页面模式跳转回列表页并 Toast 提示"保存成功"
- 提交失败时：保留表单内容不变，Toast 提示错误原因

**表单离开保护：**
- 用户修改表单内容后未保存即离开页面/关闭弹窗，弹出确认框："内容尚未保存，确定离开吗？"
- 按钮：[取消] [确定离开]

### 3.4 通用弹窗交互

**弹窗行为：**
- 点击遮罩层（弹窗外的半透明区域）不关闭弹窗（防止误操作）
- 弹窗右上角有关闭按钮（×）
- 弹窗打开时，页面滚动锁定
- ESC 键关闭弹窗（需确认离开保护，如适用）
- 弹窗支持拖拽标题栏移动位置

**确认弹窗：**
- 用于删除、禁用等破坏性操作
- 结构：标题图标（警示）+ 确认文案 + 操作按钮
- 按钮排列：[取消]（次要按钮）[确认删除/确认禁用]（警示按钮）
- 重要操作（如批量删除、禁用用户）需用户输入确认文字，输入正确后才可点击确认按钮
- 确认按钮点击后显示加载状态，操作完成后关闭弹窗并刷新列表

### 3.5 Toast 消息提示

| 类型 | 触发时机 | 自动消失时间 |
|------|----------|--------------|
| **成功 (Success)** | 保存、删除、上架、下架等操作成功 | 3秒 |
| **错误 (Error)** | 操作失败、接口异常 | 5秒，需带关闭按钮 |
| **警告 (Warning)** | 存在风险的操作提醒 | 5秒，需带关闭按钮 |
| **信息 (Info)** | 一般性提示（如导入进度） | 3秒 |

- Toast 位置：页面中上方
- 同一时间只显示一条 Toast，新的 Toast 出现时替换上一条

### 3.6 加载状态

- **骨架屏**：首次进入页面时使用，模拟页面布局的灰色占位块
- **加载动画**：列表翻页、搜索筛选时，表格区域居中显示旋转加载图标
- **按钮加载**：提交按钮内显示加载动画 + "保存中..."，按钮禁用
- **全屏加载**：大文件导入等耗时操作时，全屏遮罩 + 进度百分比

### 3.7 HTML 源码编辑器交互

用于小节内容的 HTML 源码编辑，集成在 L3 小节内容编辑预览页中。

**编辑器特性：**
- 左侧为 HTML 源码编辑区（等宽字体、代码高亮、行号显示）
- 右侧为实时预览区，模拟小程序 WebView 尺寸渲染 HTML
- 左右分栏可拖拽调整宽度
- 编辑区内容变更时，预览区实时刷新渲染结果
- 支持 Ctrl+Z 撤销 / Ctrl+Shift+Z 重做
- 支持 HTML 语法高亮（标签、属性、字符串等分别着色）
- 预览区中的图片支持 [🔄 重新生成] 操作（工作流3）

### 3.8 权限控制交互

- 无权限访问的菜单项在侧边栏中不显示
- 直接通过 URL 访问无权限页面时，跳转至 403 提示页
- 无权限的操作按钮（如删除、禁用）在页面上置灰不可点击，hover 时提示"您没有操作权限"
- 登录过期时，当前页面弹出提示"登录已过期，请重新登录"，3 秒后跳转至登录页

### 4.1 模块一：数据看板

#### 4.1.1 页面路径

`L1: 数据看板` → `L2: 数据看板首页`

#### 4.1.2 页面组成

##### 4.1.2.1 时间范围选择器 (L3)

- 位置：页面内容区顶部
- 控件类型：标签切换 + 日期范围选择器
- 预设标签：今日、昨日、近7天、近30天、自定义
- 默认选中"今日"
- 点击非自定义标签时，下面所有数据区域切换为该时间范围的数据
- 点击"自定义"标签时，展开日期范围选择器（两个日期输入框：开始日期 + 结束日期），选择完成后点击"确认"触发数据刷新
- 日期选择器限制：结束日期不能早于开始日期，最大跨度不超过 365 天

##### 4.1.2.2 核心指标卡片行

- 布局：4 个指标卡片横向排列，卡片之间间距均等
- 指标卡片内容：指标名称（上方）+ 数值（主文字，大号）+ 环比变化（右侧，箭头 + 百分比）
- 环比变化：上升绿色箭头 ↑，下降红色箭头 ↓，持平灰色横线 →
- 指标列表：总用户数、日活用户(DAU)、新增用户、今日学习
- 数值加载中：显示 "- -" 占位 + 脉冲动画
- 每个指标卡片可点击（意思是支持点击下钻 L4），点击后弹出该指标的详细统计弹窗，显示更多维度的拆解数据（按日期、按用户群等）

##### 4.1.2.3 图表区域

- 布局：2×2 网格布局，四个图表
- 图表类型：用户增长趋势（折线图）、活跃用户留存（表格/热力图）、内容消费数据（柱状图/折线图）、学习转化漏斗（漏斗图）
- 每个图表右上角有"查看详情"链接，点击跳转至对应详细报表（暂无，预留）
- 图表数据随上方时间范围选择器变化

**用户增长趋势图交互：**
- x 轴：日期
- y 轴：用户数
- 折线：总用户数（实线）、新增用户（虚线）
- hover 数据点时，显示 tooltip（日期 + 具体数值）
- 图表下方可切换显示维度：按日/按周/按月

**活跃用户留存交互：**
- 展示留存率表格，行：注册周期（Day 1, Day 2, Day 3, Day 7, Day 14, Day 30），列：日期
- 留存率数值右下角显示环比变化箭头
- 表格上方切换：新用户留存 / 活跃用户留存

**内容消费数据图交互：**
- 双 y 轴：左 y 轴为卡片学习数（柱状图），右 y 轴为答题数（折线图），x 轴为日期
- hover 数据点时，同时显示两张图的 tooltip
- 图表上方切换：按总量 / 按人均

**学习转化漏斗图交互：**
- 漏斗层级：曝光内容 → 开始学习 → 完成学习 → 完成测验 → 测验通过
- 每层显示数量和该层到下一层的转化率（百分比）
- hover 每层时，显示详细数值和转化率

##### 4.1.2.4 热门内容排行 TOP10

- 位置：图表区域下方，占满宽度
- 控件类型：表格 + 标签切换
- 标签切换：小节内容 / 知识体系 / 题目，默认为小节内容
- 表格列：排名序号、内容名称、所属章节/知识体系、学习次数、学习人数
- 排行序号 1-3 名分别显示金、银、铜色序标
- 每行可点击，点击后跳转至对应内容的详情/编辑页

### 4.2 模块二：内容管理

#### 4.2.1 知识体系

知识体系采用**三级层级模型**：知识体系 > 章节(Chapter) > 小节(Section)。每个小节对应一篇 HTML 图文内容页面，由 AI 工作流生成，小程序端通过 WebView 展示。

**核心设计原则：**
- **上架即只读**：已上架的知识体系只能查看和下架，不可编辑
- **下架方可编辑**：下架或草稿状态的知识体系可自由编辑
- **删除需等待**：必须先下架，若有用户在学习则进入 30 天删除等待期

**页面关系：**
- **L3: 内容管理页（知识体系列表）**：所有知识体系的列表入口，按状态区分操作
- **L3: 知识体系详情页（只读查看）**：仅已上架知识体系可进入，查看结构和预览小节
- **L3: 知识体系编辑页**：新建或编辑已下架/草稿的知识体系，集成 AI 生成大纲
- **L3: 小节内容编辑预览页**：编辑单篇小节的 HTML 图文内容，集成 AI 生成内容和图片重生成

##### 4.2.1.1 页面路径

```
L1: 内容管理 → L2: 知识体系
    ├── L3: 内容管理页（知识体系列表）
    │       已上架 → 跳转 L3 详情页（只读）
    │       已下架/草稿 → 跳转 L3 编辑页
    │       [+ 添加知识体系] → 跳转 L3 编辑页（新建模式）
    ├── L3: 知识体系详情页（只读，仅已上架）
    │       └── L4: 小节内容预览弹窗
    ├── L3: 知识体系编辑页（新建/编辑已下架或草稿）
    │       ├── L4: AI 生成大纲弹窗（工作流1）
    │       ├── L4: 章节增删排序
    │       ├── L4: 小节增删排序
    │       └── L4: 上架发布 / 保存草稿
    └── L3: 小节内容编辑预览页
            ├── L4: AI 生成内容（工作流2）
            ├── L4: 图片重新生成（工作流3）
            ├── L4: HTML 源码编辑
            └── L4: 实时预览 panel
```

##### 4.2.1.2 L3: 内容管理页（知识体系列表）

**进入方式：** 点击侧边栏"知识体系"

**页面组成：**
- 顶部操作栏：[+ 添加知识体系] 主按钮（跳转编辑页，新建模式）
- 搜索筛选栏：搜索知识体系名称（输入框）、状态筛选（标签切换：全部 / 已上架 / 已下架 / 删除等待中）
- 数据表格 + 分页器

**表格列：**
- 知识体系名称、章节数、小节数、难度（标签：入门/基础/进阶）、状态（标签：已上架🟢/已下架🔴/草稿📝/删除等待中⏳）、创建时间、操作

**操作列按钮（按状态区分）：**

| 知识体系状态 | 操作按钮 | 点击行为 |
|-------------|----------|----------|
| **已上架** | 查看 | 跳转至 L3 知识体系详情页（只读） |
| **已下架 / 草稿** | 编辑 | 跳转至 L3 知识体系编辑页 |
| **已下架** | 删除 | 弹出删除确认弹窗（见 4.2.1.7 删除流程） |
| **删除等待中** | 查看 | 跳转至详情页（只读），显示删除倒计时 |

**空状态：**
- 无知识体系时："暂无知识体系，点击添加第一个知识体系" + [+ 添加知识体系] 按钮

##### 4.2.1.3 L3: 知识体系详情页（只读查看）

**进入方式：** 在内容管理页点击已上架知识体系的"查看"，或点击删除等待中知识体系的"查看"

**页面组成：**
- 顶部面包屑：内容管理 > [知识体系名称]
- 顶部操作栏：[← 返回列表] 文字按钮、[下架] 按钮（仅已上架时显示）

**知识体系基本信息区：**
- 只读展示：名称、难度标签、章节数、小节数、创建时间、状态标签

**章节列表（可展开/折叠）：**
- 章节以手风琴面板展示，每个章节面板：
  - 面板头部：章节序号 + 名称 + 展开/折叠箭头
  - 面板内容：学习目标(goal)、章节概述(content)
  - 小节列表（缩进子项）：小节标题（如"1.1 Python语言简介"）
- 默认展开第一个章节
- 点击面板头部切换展开/折叠
- 顶部有 [全部展开] / [全部折叠] 切换按钮

**小节操作：**
- 点击小节标题行 → 打开小节内容预览弹窗 (L4)

**小节内容预览弹窗 (L4)：**
- 大弹窗（宽度 800px），模拟小程序 WebView 尺寸和样式
- 完整渲染小节的 HTML 图文内容
- 若小节无 HTML 内容：显示"该小节暂无内容"
- 底部按钮：[关闭]

**下架操作：**
- 点击 [下架] 按钮 → 确认弹窗："下架后小程序端将不再显示该知识体系，确定吗？"
- 确认后知识体系状态变为「已下架」，自动跳转回内容管理列表页

##### 4.2.1.4 L3: 知识体系编辑页

**进入方式：** 内容管理页 [+ 添加知识体系] 或点击已下架/草稿知识体系的"编辑"

**页面组成：**
- 顶部面包屑：内容管理 > [新增知识体系 / 编辑：名称]
- 顶部操作栏：[← 返回列表] [保存草稿]（次要按钮）[上架发布]（主按钮）

**基本信息区：**

| 字段 | 控件类型 | 必填 | 校验规则 | 默认值 |
|------|----------|------|----------|--------|
| 知识体系名称 | 文本框 | 是 | 不超过 30 字 | - |
| 难度 | 单选按钮 | 是 | 入门/基础/进阶 | 入门 |
| 显示图标 | 图标选择器 | 否 | - | 默认图标 |

**章节管理区：**
- 标题栏：章节管理 + [AI 生成大纲] 次按钮 + [+ 添加章节] 文字按钮
- 章节列表（可展开/折叠的面板，每个章节一个面板）：
  - 面板头部：拖拽手柄 + 章节名称（可编辑文本框）+ [▲▼] 排序按钮 + [删除章节] 图标按钮 + 展开/折叠箭头
  - 面板内容：
    - 学习目标（文本域，不超过 200 字）
    - 章节概述（文本域，不超过 500 字）
    - 小节列表：
      - 每行：拖拽手柄 + 小节标题（可编辑文本框）+ 知识点描述（可编辑文本域）+ [编辑内容] 文字按钮 + [删除小节] 图标按钮
      - [+ 添加小节] 文字按钮

**交互说明：**

| 操作 | 交互行为 |
|------|----------|
| **AI 生成大纲** | 弹出输入弹窗 → 输入知识体系名称 → [开始生成] → 调用工作流1 → 生成中显示加载动画 → 返回后自动填充章节和小节列表 → Toast"大纲生成成功，请检查并编辑" |
| **添加章节** | 在章节列表末尾添加空章节面板，章节名称获得焦点 |
| **删除章节** | 二次确认弹窗："确定删除该章节及其下所有小节吗？" |
| **拖拽排序** | 章节在全局拖拽排序；小节在所属章节内拖拽排序 |
| **编辑小节内容** | 点击小节行的 [编辑内容] → 跳转至 L3 小节内容编辑预览页 |

**AI 生成大纲弹窗 (L4)：**

| 字段 | 控件类型 | 必填 | 说明 |
|------|----------|------|------|
| 知识体系名称 | 文本框 | 是 | 默认为当前知识体系名称，可修改 |

- [开始生成] 主按钮 → 调用工作流1
- 生成中：弹窗内显示加载动画 + "AI 正在规划知识结构，预计需要 10-60 秒..."
- 生成完成：弹窗关闭，章节列表自动填充
- 生成超时（>120秒）：弹窗内显示"生成超时，请重试" + [重试] [取消] 按钮
- 生成失败：弹窗内显示错误信息 + [重试] [取消] 按钮

**保存与发布：**

| 按钮 | 行为 |
|------|------|
| **[保存草稿]** | 校验必填项（知识体系名称）→ 保存为草稿状态 → Toast"已保存草稿" → 停留当前页 |
| **[上架发布]** | 校验必填项（名称 + 至少1个章节 + 每章节至少1个小节）→ 校验不通过则定位到第一个缺失处 → 通过后保存并上架 → Toast"已上架发布，小程序端立即生效" → 跳转回内容管理列表页 |

**离开保护：**
- 有未保存修改时离开页面，弹出确认框："内容尚未保存，确定离开吗？" [取消] [确定离开]

##### 4.2.1.5 L3: 小节内容编辑预览页

**进入方式：** 在知识体系编辑页点击某小节的 [编辑内容]

**页面组成（左右分栏布局，可拖拽调整分栏宽度）：**

- 顶部面包屑：内容管理 > [知识体系名称] > [章节名称] > [小节标题]
- 顶部操作栏：[← 返回章节列表] [保存]（主按钮）

| 区域 | 内容 | 行为 |
|------|------|------|
| **左侧编辑区** | HTML 源码编辑器（代码高亮、行号、等宽字体） | 直接编辑 HTML 代码，实时反映到右侧预览区 |
| **右侧预览区** | 模拟小程序 WebView 渲染 HTML | 实时预览，发现图片问题可触发工作流3 |

**内容为空状态：**
- 编辑区为空，预览区显示空状态插图 + 提示："该小节暂无内容"
- 底部居中显示 [生成内容] 主按钮
- 点击 [生成内容] → 调用工作流2，传入章节名称 + 小节标题 + 知识点描述 + 小程序设计系统

**生成中状态：**
- 编辑区和预览区均显示加载动画 + "AI 正在生成图文内容，预计需要 10-60 秒..."

**生成完成状态：**
- 左侧编辑区显示 HTML 源码
- 右侧预览区实时渲染
- 底部按钮变为：[重新生成]（次按钮）+ [保存]（主按钮）

**图片重新生成 (工作流3)：**
- 预览区中每张图片右上角显示 [🔄] 悬浮按钮
- 点击 → 该图片显示加载状态 → 调用工作流3 → 返回新图片 URL → 自动替换 HTML 中对应的 `<img src>` → 预览区和编辑区同步更新
- 新图片不满意可再次点击 [🔄]，每次都是独立请求

**重新生成内容：**
- 点击 [重新生成] → 确认弹窗："重新生成将覆盖当前内容，确定吗？" → [取消] [确认重新生成]
- 确认后调用工作流2，覆盖当前 HTML

**保存：**
- 点击 [保存] → HTML 内容保存到后端 → Toast"内容已保存" → 停留当前页
- 若所属知识体系已上架，保存后小程序端立即同步更新
- 每 30 秒自动保存草稿到本地存储（防止意外关闭丢失）

##### 4.2.1.6 AI 工作流集成

知识体系编辑过程中深度集成三个 AI 工作流：

**工作流1：大纲生成**

| 项目 | 说明 |
|------|------|
| **触发位置** | 知识体系编辑页 [AI 生成大纲] 按钮 |
| **输入** | 知识体系名称 |
| **输出** | 结构化 JSON：章节列表（章节名、学习目标、概述）+ 每章节下的小节列表（小节标题、知识点描述） |
| **生成后行为** | 自动填充章节列表和小节列表到编辑页，运营人员可人工调整后保存 |
| **超时** | 120 秒，超时提示重试 |

**工作流2：小节内容生成**

| 项目 | 说明 |
|------|------|
| **触发位置** | 小节内容编辑预览页 [生成内容] 按钮 |
| **输入** | 章节名称 + 小节标题 + 知识点描述 + 小程序设计系统 |
| **输出** | JSON：`section_html`（完整 HTML 图文页面代码）+ `new_blk_designs`（图片设计详情与提示词） |
| **生成后行为** | HTML 显示在左侧编辑区，右侧预览区实时渲染，运营人员可编辑后保存 |
| **超时** | 120 秒 |

**工作流3：图片重新生成**

| 项目 | 说明 |
|------|------|
| **触发位置** | 预览区图片旁的 [🔄] 按钮 |
| **输入** | 图片生成提示词（取自工作流2返回的 `new_blk_designs`） |
| **输出** | 新图片 URL |
| **生成后行为** | 自动替换 HTML 中对应 `<img src>`，编辑区和预览区同步更新 |

##### 4.2.1.7 删除流程

**删除状态机：**

```
已上架 → [下架] → 已下架 → [删除]
                              │
                              ├── 无用户学习中 → 确认后直接删除
                              │
                              └── 有用户学习中 → 进入「删除等待中」
                                                    │
                                                    ├── 对未学习用户：不可见
                                                    ├── 对在学习用户：可见（可继续学完）
                                                    └── 30天后 → 强制删除
```

**删除确认弹窗：**
- 标题图标：⚠️
- 文案：
  - 无用户学习中：`确定删除知识体系"[名称]"吗？包括其下 N 个章节和 M 个小节，删除后不可恢复。`
  - 有用户学习中：`该知识体系下有 X 名用户正在学习中，删除后将进入 30 天等待期。期间对未学习用户不可见，在学习用户可继续学完。30 天后强制删除。确定继续吗？`
- 需输入确认文字："确认删除"（4 个字），输入正确后 [确认删除] 按钮可用
- 按钮：[取消] [确认删除]（警示色）

**删除等待期处理：**
- 知识体系在列表中标记为"删除等待中"状态（⏳标签 + 剩余天数倒计时）
- 运营人员可在等待期内点击"查看"进入详情页
- 详情页显示删除倒计时 + [撤销删除] 按钮 → 点击恢复为"已下架"状态
- 期满后系统自动删除数据，无需人工干预

#### 4.2.2 题目管理

##### 4.2.2.1 页面路径

`L1: 内容管理` → `L2: 题目管理` → `L3: 题目列表页`

##### 4.2.2.2 题目列表页组成与交互

**页面组成：**

- 顶部操作区：[+ 新增题目] [批量导入]（次按钮）[批量导出]
- 搜索筛选栏：题目内容（输入框）、题目类型（多选下拉）、难度（单选按钮）、状态（多选下拉）、关联知识体系（下拉选择器）
- 表格操作行：[批量上架] [批量下架] [批量删除]
- 数据表格 + 分页器

**表格列：**
- 复选框、题目内容（截断显示前 40 字 + 省略号，hover 显示完整内容）、题目类型（标签：单选/多选/判断）、关联小节（点击可跳转至小节预览）、难度、答题人数、正确率、状态、操作

**新增/编辑题目页 (L3)：**

独立页面，面包屑：内容管理 > 题目管理 > [新增题目 / 编辑题目]

**表单字段：**

| 字段 | 控件类型 | 必填 | 校验规则 |
|------|----------|------|----------|
| 题目类型 | 单选按钮 | 是 | 选择后调整下方选项控件 |
| 题目内容 | 文本域 | 是 | 不超过 500 字 |
| 选项 A | 文本框 | 是 | 不超过 200 字 |
| 选项 B | 文本框 | 是 | 不超过 200 字 |
| 选项 C | 文本框 | 是 | 不超过 200 字 |
| 选项 D | 文本框 | 是 | 不超过 200 字 |
| 正确答案 | 由题目类型决定 | 是 | - |
| 答案解析 | 文本域 | 是 | 不超过 1000 字 |
| 关联小节 | 级联选择器（知识体系→章节→小节） | 是 | 至少选 1 个小节 |
| 难度 | 单选按钮 | 是 | 入门/基础/进阶 |
| 状态 | 开关（草稿/已上架） | 是 | - |

**正确答案控件随题目类型联动变化：**

| 题目类型 | 正确答案控件 | 交互 |
|----------|--------------|------|
| 单选题 | 单选按钮（A/B/C/D） | 4 选 1 |
| 多选题 | 复选框（A/B/C/D） | 4 选 2-3，选满 3 个后其余置灰 |
| 判断题 | 单选按钮（正确/错误） | 2 选 1 |

**批量导入页 (L3)：**

独立页面，面包屑：内容管理 > 题目管理 > 批量导入

**页面组成与交互流程：**

1. **下载模板**：页面顶部提示"请先下载导入模板，按模板格式填写题目信息"，[下载模板] 链接（点击下载 Excel 模板）
2. **上传文件**：拖拽/点击上传区，支持 .xlsx / .xls 格式，单个文件不超过 5MB
3. **文件校验**：上传后自动校验，显示校验结果：
   - 总行数、成功行数、失败行数
   - 失败行列表（行号 + 错误原因）
   - 按钮：[重新上传] [仅导入成功行]
4. **导入执行**：点击"仅导入成功行"后，显示进度条（N/总数），导入期间按钮禁用
5. **导入完成**：显示结果统计（导入成功 N 条，跳过 N 条），[返回列表] 按钮
6. **部分失败处理**：如存在失败行，可点击"下载失败行"导出含错误标记的 Excel

**批量导出交互 (L3)：**

- 点击[批量导出]按钮，弹出导出条件配置弹窗
- 弹窗字段：题目类型（多选）、难度（多选）、知识体系（下拉）、状态（多选）

`L1: 系统配置` → `L2: 日志审计` → `L3: 日志查询页`

##### 4.5.3.2 日志查询页组成与交互

**页面组成：**

- 搜索筛选区：
  - 操作时间范围（日期时间范围选择器）
  - 操作模块（多选下拉：全部/数据看板/内容管理/用户管理/运营管理/系统配置）
  - 操作类型（多选下拉：登录/新增/编辑/删除/上架/下架/导出/禁用/其他）
  - 操作人员（输入框，搜索账号）
  - [搜索] [重置] 按钮
- [导出日志] 按钮
- 数据表格 + 分页器（按时间倒序排列）

**表格列：**
- 操作时间、操作人员、操作模块、操作类型（标签）、操作对象、操作内容（截断显示，hover/点击展开详细快照对比）、IP 地址

**操作内容展开交互：**
- 操作内容单元格显示摘要文字
- hover 或点击时，展开 tooltip/弹出层 显示详情：
  - 新增：显示新增的数据概要
  - 编辑：显示变更字段的前后值对比（旧值 → 新值）
  - 删除：显示被删除数据的概要信息

**敏感操作标记：**
- 批量删除、用户禁用、积分调整等敏感操作，行背景高亮显示（浅红色），操作类型列旁标记"敏感"标签

**日志保留说明：**
- 表格底部显示："系统保留最近 180 天操作日志，超期自动归档。如需查询更早日志，请联系管理员。"

### 5.1 全局错误页面

| 页面/状态 | 触发条件 | 页面内容 |
|-----------|----------|----------|
