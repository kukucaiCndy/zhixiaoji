# 知识层级重构 - 前端迁移指南

> **版本**: V2.2 | **日期**: 2026-06-06 | **后端灰度**: 新旧接口共存，旧接口逐步废弃

---

## 一、变更概述

知识体系层级从 **三层** 扩展为 **四层**，新增"分类（Category）"作为顶层：

```
旧：知识体系 → 篇章 → 章节
新：分类 → 知识章节 → 章节 → 小结（预留）
```

| 旧概念 | 旧表/实体 | 新概念 | 新表/实体 | 说明 |
|--------|-----------|--------|-----------|------|
| 知识体系 | `knowledge_systems` | **分类** | `categories` | 新增顶层，如"编程"、"计算机" |
| 篇章 | `knowledge_chapters` | **知识章节** | `knowledge_chapters` | 实体类重命名，表不变 |
| 章节 | `knowledge_sections` | 章节 | `knowledge_sections` | 不变 |
| — | — | 小结 | 预留 | 未来扩展 |

## 二、新增 API（必须跟进）

### 2.1 分类列表

```
GET /knowledge/categories
```

**查询参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|:---:|------|
| `status` | string | 否 | 筛选：`published` / `draft` |
| `keyword` | string | 否 | 按名称模糊搜索 |

**响应示例**：

```json
{
  "code": 0,
  "data": [
    {
      "id": "uuid",
      "name": "编程",
      "icon": "https://...",
      "description": "掌握编程语言",
      "sortOrder": 0,
      "chapterCount": 4,
      "sectionCount": 42,
      "status": "published",
      "createdAt": "2026-06-06T00:00:00Z",
      "updatedAt": "2026-06-06T00:00:00Z"
    }
  ]
}
```

### 2.2 分类详情（含知识章节列表）

```
GET /knowledge/categories/:id
```

**响应示例**：

## 三、变更 API（需修改调用方）

### 3.1 知识章节列表

**路由不变**：`GET /knowledge/chapters`

**查询参数变更**：

| 参数 | 旧 | 新 | 说明 |
|------|-----|-----|------|
| `knowledgeSystemId` | 筛选知识体系 | **废弃** | 改用 `categoryId` |
| `categoryId` | — | **新增** | 按分类筛选 |

**示例**：

```diff
- GET /knowledge/chapters?knowledgeSystemId=xxx
+ GET /knowledge/chapters?categoryId=xxx
```

### 3.2 知识章节详情

**路由不变**：`GET /knowledge/chapters/:id`

**响应字段变更**：

```diff
{
  "id": "uuid",
  "title": "Python基础",
- "knowledgeSystemId": "uuid",
+ "categoryId": "uuid",
  "description": "...",
  "goal": "...",
  "difficulty": "beginner",
  "sortOrder": 0,
  "sectionCount": 12,
  "status": "published",
  "sections": [ ... ]
}
```

### 3.3 章节列表

**路由不变**：`GET /knowledge/sections`

**查询参数不变**：`?chapterId=xxx`（指向知识章节）

## 四、TypeScript 类型变更

### 新增类型

```typescript
// 分类
interface Category {
  id: string;
  name: string;
  icon: string | null;
  description: string | null;
  sortOrder: number;
  chapterCount: number;
  sectionCount: number;
  status: string;
  createdAt: string;
  updatedAt: string;
}

// 分类详情（含知识章节）
interface CategoryDetail extends Category {
  chapters: KnowledgeChapterSummary[];
}

// 查询参数
interface CategoryQueryParams {
  status?: string;
  keyword?: string;
}
```

### 变更类型

```typescript
// Chapter 改名为 KnowledgeChapter（旧名保留兼容）
interface KnowledgeChapter {
  id: string;
  title: string;
  description: string | null;
  goal: string | null;
  categoryId: string | null;        // ← 原名 knowledgeSystemId
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  sortOrder: number;
  status: string;
  sectionCount?: number;
  createdAt: string;
  updatedAt: string;
}

// ChapterQueryParams
interface ChapterQueryParams {
  status?: string;
  sortBy?: string;
  categoryId?: string;              // ← 原名 knowledgeSystemId
}
```

### 兼容说明

旧类型名 `Chapter`、`ChapterSummary`、`ChapterDetail` 仍可 import，实际指向新类型，**逐步迁移到 `KnowledgeChapter` 系列即可**。

## 五、SDK 使用指南

### 小程序 SDK (`@zhixiaoji/api-sdk-wechat`)

```typescript
import { KnowledgeApi } from '@zhixiaoji/api-sdk-wechat';

const api = new KnowledgeApi(client);

// 新：获取分类列表
const { data: categories } = await api.listCategories({ status: 'published' });

// 新：获取分类详情（含知识章节）
const { data: category } = await api.getCategory(categoryId);

// 变：获取知识章节（参数改用 categoryId）
const { data: chapters } = await api.listKnowledgeChapters({ categoryId });
const { data: chapter } = await api.getKnowledgeChapter(chapterId);

// 不变：章节列表
const { data: sections } = await api.listSections({ chapterId });
```

### Web 管理后台 SDK (`@zhixiaoji/api-sdk-web`)

新增分类管理接口（需 `x-internal-key` 请求头）：

```typescript
import { KnowledgeApi } from '@zhixiaoji/api-sdk-web';

// 创建分类
await api.createCategory({ name: '编程', icon: '...', sortOrder: 0 });

// 更新分类
await api.updateCategory(id, { name: '计算机科学' });

// 删除分类（仅草稿）
await api.deleteCategory(id);

// 上架/下架
await api.publishCategory(id);
await api.unpublishCategory(id);
```

## 六、前端页面调整对照

### 小程序端

| 页面 | 当前路由 | 调整内容 |
|------|----------|----------|
| 学习页 | `pages/learn/index` | 改为调用 `GET /categories` 展示方块图标网格 |
| 分类详情 | `pages/learn/categories` | **新增页面**，调用 `GET /categories/:id` |
| 知识章节 | `pages/learn/knowledge-chapters` | **新增页面**，调用 `GET /chapters/:id` |
| 章节列表 | `pages/learn/sections` | 不变，调用 `GET /sections?chapterId=xxx` |

### Web 管理后台

| 功能 | 当前 | 调整内容 |
|------|------|----------|
| 分类管理 | 无 | **新增**：分类 CRUD（列表/创建/编辑/上架/下架） |
| 知识章节管理 | 篇章管理 | 创建/编辑时选择所属"分类"而非"知识体系" |
| 章节管理 | 不变 | 无需调整 |
