## 一、项目概述

### 1.1 项目定位

知晓记管理后台是面向运营人员的一站式内容管理与运营配置平台，基于 Vue 3 技术栈构建的 Web 单页应用（SPA），为「知晓记」微信小程序提供内容管理、用户管理、运营配置及数据监控能力。

### 1.2 核心目标

| 目标 | 说明 |
|------|------|
| **高效率开发** | 基于 Vue 3 + Element Plus 快速构建 20+ 管理页面 |
| **易维护扩展** | 组件化架构设计，支持 AI 工作流等未来功能扩展 |
| **预览驱动** | 所有内容编辑支持实时预览，确认效果后再发布 |
| **权限可控** | 完善的权限管理体系，支持菜单级和按钮级权限控制 |

### 5.2 路由守卫策略

```typescript
// 路由守卫流程
router.beforeEach(async (to, _, next) => {
  // 1. 检查是否登录（token 是否存在）
  const isLoggedIn = !!userStore.token

  if (!isLoggedIn && to.path !== '/login') {
    return next('/login')
  }

  if (isLoggedIn && to.path === '/login') {
    return next('/dashboard')
  }

  // 2. 动态加载权限路由（仅在首次登录时）
  if (isLoggedIn && !permissionStore.isLoaded) {
    const menus = await userStore.getUserMenus()
    const routes = permissionStore.generateRoutes(menus)
    routes.forEach(route => router.addRoute(route))
    permissionStore.isLoaded = true
    return next(to.path) // 重定向以触发新路由匹配
  }

  // 3. 检查页面级权限
  if (to.meta?.roles && !permissionStore.hasRole(to.meta.roles)) {
    return next('/403')
  }

  next()
})
```

## 六、状态管理设计

### 6.1 Store 划分

| Store | 职责 | 核心状态 |
|-------|------|---------|
| **appStore** | 应用全局状态 | 侧边栏折叠、主题、语言、页面标题 |
| **userStore** | 用户认证与信息 | token、用户信息、权限列表、菜单列表 |
| **permissionStore** | 权限管理 | 已加载路由、按钮权限标识集合 |

### 6.2 Pinia 使用规范

```typescript
// store/user.ts - 示例
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { loginApi, getUserInfoApi } from '@/api/modules/user'
import type { UserInfo, LoginParams } from '@/api/types/user'

export const useUserStore = defineStore('user', () => {
  const token = ref(localStorage.getItem('token') || '')
  const userInfo = ref<UserInfo | null>(null)

  const isLoggedIn = computed(() => !!token.value)

  async function login(params: LoginParams) {
    const res = await loginApi(params)
    token.value = res.token
    localStorage.setItem('token', res.token)
  }

  async function fetchUserInfo() {
    userInfo.value = await getUserInfoApi()
  }

  function logout() {
    token.value = ''
    userInfo.value = null
    localStorage.removeItem('token')
  }

  return { token, userInfo, isLoggedIn, login, fetchUserInfo, logout }
})
```

## 七、API 层设计

### 7.1 axios 实例封装

```typescript
// src/api/request.ts
import axios from 'axios'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/store/user'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 15000,
})

// 请求拦截器：注入 token
request.interceptors.request.use((config) => {
  const userStore = useUserStore()
  if (userStore.token) {
    config.headers.Authorization = `Bearer ${userStore.token}`
  }
  return config
})

// 响应拦截器：统一错误处理
request.interceptors.response.use(
  (response) => response.data,
  (error) => {
    const status = error.response?.status
    switch (status) {
      case 401:
        // token 过期，跳转登录
        useUserStore().logout()
        window.location.href = '/login'
        break
      case 403:
        ElMessage.error('权限不足')
        break
      case 500:
        ElMessage.error('服务器错误，请稍后重试')
        break
      default:
        ElMessage.error(error.message || '请求失败')
    }
    return Promise.reject(error)
  },
)

export default request
```

```typescript
  createChapter: (data: ChapterCreateParams) =>
    request.post<Chapter>('/api/admin/chapters', data),

  updateChapter: (id: number, data: ChapterUpdateParams) =>
    request.put<Chapter>(`/api/admin/chapters/${id}`, data),

  deleteChapter: (id: number) =>
    request.delete(`/api/admin/chapters/${id}`),

  // 卡片管理
  getCards: (params: CardQueryParams) =>
    request.get<PaginatedResult<Card>>('/api/admin/cards', { params }),

  createCard: (data: CardCreateParams) =>
    request.post<Card>('/api/admin/cards', data),
}
```

### 7.3 接口调用规范

- 所有 API 调用统一通过 `src/api/modules/` 下的模块化函数
- 禁止在页面组件中直接使用 `axios` 或 `request`
- 接口返回值必须有明确的 TypeScript 类型定义
- 业务逻辑层面的错误（如表单校验失败）在 Service 层 catch 后，通过返回值传递错误信息

### 9.2 流式接收实现

```typescript
// composables/useAIGenerate.ts
import { ref } from 'vue'
import { ElMessage } from 'element-plus'

export function useAIGenerate() {
  const content = ref('')
  const isGenerating = ref(false)
  const error = ref<string | null>(null)

  async function generate(params: AIGenerateParams) {
    content.value = ''
    isGenerating.value = true
    error.value = null

    try {
      const response = await fetch('/api/ai/generate', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(params),
      })

      if (!response.ok) {
        throw new Error(`生成失败: ${response.status}`)
      }

      const reader = response.body.getReader()
      const decoder = new TextDecoder()

      while (true) {
        const { done, value } = await reader.read()
        if (done) break
        content.value += decoder.decode(value, { stream: true })
      }
    } catch (e: any) {
      error.value = e.message
      ElMessage.error(e.message)
    } finally {
      isGenerating.value = false
    }
  }

  function reset() {
    content.value = ''
    isGenerating.value = false
    error.value = null
  }

  return { content, isGenerating, error, generate, reset }
}
```

```typescript
app.directive('permission', {
```
