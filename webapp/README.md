# 知晓记管理后台

> 知晓记小程序的 Web 端运营管理后台

## 技术栈

Vue 3 + TypeScript + Vite + Element Plus + Pinia + ECharts + SCSS

## 当前状态

🟢 M1-M6 页面开发完成 | 🔴 待联调测试

## 快速启动

```bash
./scripts/webapp-manager.sh start   # 开发服务器 http://localhost:3000
./scripts/webapp-manager.sh debug   # Chrome + DevTools 调试
./scripts/build.sh build            # 编译构建
```
