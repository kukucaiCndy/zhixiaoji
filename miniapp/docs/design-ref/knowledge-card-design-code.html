什么是 Flexbox？它的核心概念是什么？

思考一下：当你需要在一行或一列中排列多个元素时，传统布局方式有什么局限性？

👆 点击翻转查看解释

💡

概念解释

Flexbox（弹性盒子）是一种一维布局模型，能够高效地在行或列方向上分配空间和对齐元素。

🌱

生活类比

想象一个行李箱（容器），里面的物品可以沿着行李箱的长边排列。箱子可以调整大小，物品也可以根据剩余空间自动伸缩。

💻

代码示例

.container { display: flex; justify-content: center; align-items: center; }

📌

要点总结

✦主轴和交叉轴是 Flexbox 的核心概念

✦justify-content 控制主轴对齐

✦align-items 控制交叉轴对齐

✦flex 属性控制子元素的伸缩比例
