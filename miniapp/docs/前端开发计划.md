## 一、总体开发策略

### 1.1 分阶段原则

前端开发严格对齐后端 **5 个 Phase**，每个阶段包含：

| 环节 | 说明 |
|------|------|
| **① 页面开发** | 根据 UI 设计稿开发页面结构和样式 |
| **② 组件封装** | 提取复用组件，完善组件库 |
| **③ 状态管理** | 实现页面状态和数据流 |
| **④ API 对接** | 对接后端 SDK，实现数据交互 |
| **⑤ 联调测试** | 与后端联调，修复问题 |

### 1.2 技术栈

| 层级 | 技术方案 | 说明 |
|------|----------|------|
| **框架** | 原生微信小程序 | 不使用第三方框架，保持轻量 |
| **样式** | WXSS + rpx | 响应式单位，适配多屏幕 |
| **状态管理** | MobX-MiniApp | 轻量级状态管理 |
| **HTTP 请求** | wx.request 封装 | 统一拦截、错误处理 |
| **UI 组件** | 自定义组件库 | 基于设计系统开发 |
| **设计稿** | Pixso MCP | 通过 MCP 获取设计稿 |

### 1.3 目录结构规范

```
miniapp/
├── app.js                      # 应用入口
├── app.json                    # 全局配置
├── app.wxss                    # 全局样式
├── utils/                      # 工具函数
│   ├── request.js              # HTTP 请求封装
│   ├── storage.js              # 本地存储封装
│   ├── auth.js                 # 认证相关工具

├── services/                   # API 服务层
│   ├── auth-service.js         # 认证服务
│   ├── user-service.js         # 用户服务
│   └── ...

│   ├── user-store.js           # 用户状态
```

### 2.4 页面详细说明

#### 2.4.1 启动页 (pages/splash/index)

**功能逻辑**：
```
启动页加载
    │
    ├── 检查本地 Token
    │       ├── 有 Token → 调用 /auth/me 验证
    │       │       ├── 有效 → 跳转到首页
    │       │       └── 过期 → 尝试刷新 Token
    │       │               ├── 成功 → 跳转到首页
    │       │               └── 失败 → 跳转到登录引导页
    │       │
    │       └── 无 Token → 跳转到登录引导页
    │
    └── 显示开屏广告（如有配置）
```

**需要开发**：
- 启动页 UI
- 登录状态检查逻辑
- Token 刷新逻辑
- 页面跳转逻辑

#### 2.4.2 登录引导页 (pages/auth/login-guide)

**功能逻辑**：
```
登录引导页
    │
    ├── 显示产品 Logo 和 Slogan
    │
    ├── 点击"微信一键登录"
    │       ├── 调用 wx.login() 获取 code
    │       ├── 调用后端 /auth/miniapp/login
    │       ├── 保存 Token 和用户信息
    │       └── 跳转到首页
    │
    └── 点击"游客模式"
            └── 跳转到首页（部分功能受限）
```

**需要开发**：
- 登录引导页 UI
- 微信登录 API 调用
- 游客模式逻辑

#### 2.4.3 我的页 (pages/profile/index)

**页面结构**：
```
┌─────────────────────────┐
│  用户信息卡片            │  ← 头像、昵称、等级、积分
├─────────────────────────┤
│  功能入口网格            │  ← 积分商城、排行榜、成就等
├─────────────────────────┤
│  学习数据概览            │  ← 学习天数、卡片数、正确率
├─────────────────────────┤
│  设置入口列表            │  ← 主题、通知、关于等
└─────────────────────────┘
```

**需要开发**：
- 用户信息展示
- 功能入口网格
- 学习数据展示（静态数据，Phase 3 接入真实数据）
- 设置入口

#### 2.4.4 用户信息编辑页 (pages/profile/edit-profile)

**功能**：
- 修改昵称
- 修改头像（调用 wx.chooseImage + wx.uploadFile）
- 保存修改

## 七、开发规范

### 7.1 代码规范

- 使用 ESLint 进行代码检查
- 变量命名使用驼峰命名法
- 组件文件名使用小写短横线连接
- 页面文件放在 pages/ 目录下，每个页面一个文件夹

### 7.2 样式规范

- 使用 rpx 作为尺寸单位
- 颜色使用 CSS 变量管理
- 间距使用 8rpx 的倍数（8、16、24、32...）

### 7.3 提交规范

```
feat: 新功能
fix: 修复问题
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具相关
```
