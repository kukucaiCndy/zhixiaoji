> **版本**：V1.0  
> **创建日期**：2026-04-29  
> **状态**：待审阅  
> **适用对象**：后端开发团队、前端开发团队（WebApp Vue 3 + 微信小程序）

## 一、总体开发策略

### 1.1 分阶段原则

项目按 **业务模块** 划分为 5 个阶段，每个阶段包含：

| 环节 | 说明 |
|------|------|
| **① 后端 API 接口定义** | 先定义接口请求/响应契约，产出 SDK API 文档 |
| **② 后端业务逻辑开发** | 实现 Controller → Service → TypeORM Entity 完整链路 |
| **③ 前端开发** | WebApp（Vue 3）和微信小程序同步开发 |
| **④ SDK 文档更新** | 阶段完成后更新 SDK 接口文档，通知前端团队 |
| **⑤ 联调与验收** | 前后端联调，通过测试用例后标记完成 |

### 1.2 交付物标准

| 交付物 | 说明 |
|--------|------|
| **API 接口文档** | 每阶段更新 `doc/后端接口规范.md`，标注版本号 |
| **API SDK 包** | `packages/api-sdk/` 内含 TypeScript 类型定义 + HTTP 客户端封装 |
| **SDK 使用说明** | `packages/api-sdk/README.md` 包含接入指南、示例代码 |
| **数据库 Migration** | TypeORM Migration 文件，可回滚 |
| **Docker 镜像** | 每阶段服务可独立构建部署 |

### 1.3 前端 SDK 策略

```
后端定义接口契约（OpenAPI / TypeScript 类型）
    │
    ▼
生成 API SDK 包（@zhixiaoji/api-sdk）
    │
    ├── 提供 TypeScript 类型定义（请求/响应 DTO）
    ├── 提供 HTTP 客户端封装（自动处理 Token 注入、错误统一处理）
    │
    ├── WebApp (Vue 3) 通过 npm 引入 SDK
    │
    └── 微信小程序 通过 copy 或子包引入 SDK（小程序不支持 npm 全量）
```

## 三、Phase 1：认证授权服务 + 项目基建（当前阶段）

### 8.2 各阶段 SDK 维护节奏

| 阶段 | SDK 操作 | 说明 |
|:----:|----------|------|
| Phase 1 | **创建 SDK 骨架** | 搭建目录结构、实现 HTTP 客户端、Auth 模块类型和 API 封装 |
| Phase 2 | **维护 SDK** | 新增 Knowledge 内部类型定义（供 Core Service 开发用） |
| Phase 3 | **扩展 SDK** | 新增笔记、学习记录、复习、文件上传模块的类型和 API 封装 |
| Phase 4 | **扩展 SDK** | 新增积分、文具、等级、成就、排行榜模块 |
| Phase 5 | **完善 SDK** | 新增数据看板、广告位、运营配置模块，全量回归测试 |

### 8.3 SDK 使用示例

```typescript
// WebApp (Vue 3) 中使用 SDK
import { createApiClient } from '@zhixiaoji/api-sdk';

const client = createApiClient({
  baseURL: '/api/v1',
  storage: localStorage,  // Token 持久化到 localStorage
});

// 小程序登录
const { data } = await client.auth.miniappLogin({ code: 'wx-code' });
client.setToken(data.accessToken);

// 创建笔记（自动携带 Token）
const note = await client.core.notes.create({
  title: '我的笔记',
  content: '笔记内容',
  cardId: 'card-xxx',
});
```

```typescript
// 微信小程序中使用 SDK（适配 wx storage）
import { createApiClient } from '@zhixiaoji/api-sdk';

const wxStorage = {
  getItem: (key: string) => wx.getStorageSync(key),
  setItem: (key: string, value: string) => wx.setStorageSync(key, value),
  removeItem: (key: string) => wx.removeStorageSync(key),
};

const client = createApiClient({
  baseURL: 'https://api.zhixiaoji.com/api/v1',
  storage: wxStorage,
});
```
