## 一、设计系统概述

### 1.1 设计理念

知晓记作为AI编程学习工具，采用**"清新知性、专注学习"**的设计调性，通过简洁的界面、柔和的色彩和流畅的交互，为用户创造沉浸式的学习体验。

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **简洁清晰** | 减少视觉干扰，让内容成为焦点 |
| **渐进呈现** | 信息分层展示，避免认知过载 |
| **即时反馈** | 每个操作都有明确的视觉反馈 |
| **一致性** | 统一的组件、色彩、间距规范 |
| **可访问性** | 符合WCAG AA标准，支持深色模式 |

### 2.2 L1 一级页面（Tab页）详细说明

#### 2.2.1 首页 (pages/home/index)

**页面定位**：用户打开小程序后的默认页面，展示学习概览和今日任务

**核心模块**：
| 模块 | 说明 | 优先级 |
|------|------|--------|
| 顶部Banner | 轮播运营位，支持配置 | P1 |
| 用户概览 | 头像、昵称、连续打卡天数、当前积分 | P1 |
| 今日学习 | 今日待学习卡片数、待复习数量 | P1 |
| 学习进度 | 各篇章学习进度可视化 | P2 |
| 每日挑战入口 | 快速进入每日10题挑战 | P1 |
| 推荐内容 | 基于学习历史的个性化推荐 | P3 |
| 排行榜入口 | 快速查看榜单 | P2 |

**交互说明**：
- 下拉刷新：刷新学习数据
- Banner点击：跳转对应页面
- 模块自定义：支持长按拖拽排序、显示/隐藏

#### 2.2.2 学习页 (pages/learn/index)

**页面定位**：知识体系展示和学习的核心入口

**核心模块**：
| 模块 | 说明 | 优先级 |
|------|------|--------|
| 学习路径切换 | 主线/快速/兴趣/补弱路径切换 | P1 |
| 知识体系树 | 六大篇章展开式目录 | P1 |
| 当前学习进度 | 最近学习的章节快速续学 | P1 |
| 搜索入口 | 搜索知识卡片 | P2 |
| 收藏夹入口 | 快速查看收藏内容 | P2 |

**交互说明**：
- 篇章展开/收起：点击展开子章节
- 章节状态：未解锁/学习中/已完成视觉区分
- 长按章节：显示章节详情弹窗

#### 2.2.3 笔记页 (pages/note/index)

**页面定位**：个人笔记管理和查看

**核心模块**：
| 模块 | 说明 | 优先级 |
|------|------|--------|
| 搜索栏 | 按关键词/标签/知识点搜索 | P1 |
| 分类筛选 | 系统分类/自定义标签/时间/审核状态 | P1 |
| 笔记列表 | 卡片式布局，显示标题、摘要、关联知识点 | P1 |
| 新建按钮 | 全局悬浮按钮，快速记笔记 | P1 |

**交互说明**：
- 左滑笔记：显示编辑/删除操作
- 点击笔记：进入笔记详情
- 筛选切换：实时筛选笔记列表

#### 2.2.4 我的页 (pages/profile/index)

**页面定位**：个人中心，展示用户信息和功能入口

**核心模块**：
| 模块 | 说明 | 优先级 |
|------|------|--------|
| 用户信息 | 头像、昵称、等级、积分余额 | P1 |
| 功能入口网格 | 积分商城、排行榜、成就、学习统计、错题本、收藏夹 | P1 |
| 学习数据 | 累计学习天数、完成卡片数、答题正确率 | P2 |
| 设置入口 | 主题设置、复习计划、通知设置等 | P1 |

**交互说明**：
- 点击头像：进入个人资料编辑
- 功能入口：点击进入对应页面
- 积分显示：点击跳转积分商城

### 2.3 L2 二级页面详细说明

#### 2.3.1 知识卡片详情 (pages/learn/card-detail)

**页面结构**：
```
┌─────────────────────────┐
│  返回  知识点名称   收藏 │  ← 导航栏
├─────────────────────────┤
│  难度标签  预计时长      │  ← 元信息
├─────────────────────────┤
│                         │
│      卡片正面内容        │  ← 概念问题/标题
│                         │
│    [查看解释]           │  ← 翻转按钮
│                         │
├─────────────────────────┤
│  [记笔记]  [有点难]     │  ← 操作栏
└─────────────────────────┘
```

**卡片背面**：
- 概念解释（通俗语言）
- 生活类比（图文）
- 代码示例（如有）
- 要点总结（3-5条）
- 延伸阅读推荐

**交互说明**：
- 点击"查看解释"：卡片翻转动画展示背面
- 左右滑动：切换到上一张/下一张卡片
- 点击"记笔记"：底部弹出笔记编辑面板

#### 2.3.2 刷题练习 (pages/learn/quiz)

**页面结构**：
```
┌─────────────────────────┐
│  返回  章节练习    进度  │  ← 导航栏（1/10）
├─────────────────────────┤
│                         │
│      题目内容            │  ← 题干
│                         │
│  ○ 选项A                │
│  ○ 选项B                │  ← 选项区
│  ○ 选项C                │
│  ○ 选项D                │
│                         │
├─────────────────────────┤
│      [确认答案]         │  ← 提交按钮
└─────────────────────────┘
```

**答题后状态**：
- 正确：绿色反馈，显示简要解析，自动进入下一题
- 错误：红色反馈，显示详细解析，关联知识点入口

**交互说明**：
- 选择选项：高亮选中状态
- 确认答案：提交并显示结果
- 左右滑动：切换上一题/下一题（已答题目）

#### 2.3.3 笔记编辑 (pages/note/edit)

```
└─────────────────────────┘
```

**交互说明**：
- 富文本编辑：支持文字样式、插入图片、代码块
- 自动保存：每30秒自动保存草稿
- 返回确认：有未保存内容时提示确认

### 3.1 导航组件

| 属性 | 规范 |
|------|------|
| **高度** | 88rpx (44px) |
| **背景** | 白色/主题色 |
| **标题** | 18px, 居中, 字体加粗 |
| **返回按钮** | 左侧，24x24px图标 |
| **右侧操作** | 最多2个，图标或文字 |

- 标准版：返回 + 标题 + 操作
