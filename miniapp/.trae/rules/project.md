## 核心原则（优先级从高到低）

### ⛔ 最高优先级：严禁修改第三方代码

1. **禁止修改 SDK 源码**：`node_modules/` 目录下所有代码属于后端 SDK 团队交付物，前端无权修改。
2. **禁止修改 SDK 构建产物**：`miniprogram_npm/` 目录下的内容由 DevTools "构建 npm" 自动生成，**绝不手动编辑**。
3. **禁止修改后端接口行为**：不得通过前端 hack 手段绕过或改变后端 API 的预期行为。
4. **发现 SDK/后端问题时**：明确记录根因 → 向后端团队提交正式整改要求 → 等待后端修复后再次验证。**绝不自行修改来绕过。**
5. **禁止前端开发主动关闭bug，bug状态只能改为已修复或者待修复**
### 前端项目原则

这是一个纯粹的前端项目。在遇到调用后端问题后，需要严格按照后端 SDK 文档进行调用。如果发现后端 SDK 有问题，则直接返回问题原因在后端。**不要尝试去强行改变前端业务逻辑来适配后端**。
